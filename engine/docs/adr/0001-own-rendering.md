# ADR-0001: Рисуем каждый пиксель сами

- Статус: принято
- Дата: 2026-11-17

## Контекст

Кроссплатформенный UI делают двумя способами:

1. **Обёртки над нативными контролами** (React Native, .NET MAUI, wxWidgets): кнопка — это настоящая кнопка ОС.
2. **Собственная отрисовка** (Flutter, Gio, Fyne, Compose Multiplatform): ОС даёт только окно и события,
   всё остальное рисует движок.

## Решение

Собственная отрисовка. Платформа даёт окно, поверхность для пикселей, события ввода и сервисы
(буфер обмена, IME, доступность, курсоры). Всё, что видно на экране, рисует Gexago.

## Альтернативы

- Нативные контролы: «родной» вид бесплатно, но на каждой платформе свой набор контролов, свои баги
  и свой лэйаут — общий знаменатель беднее каждой платформы. Учебной ценности почти нет: изучаешь чужие API.

## Последствия

- Одинаковый вид и поведение на всех платформах; пиксель-в-пиксель тестируемо.
- Это единственный путь по-настоящему изучить лэйаут, растеризацию, текст и ввод.
- Платим: свой текстовый стек, свой ввод текста, своя доступность. Приложение не выглядит «нативно»
  без отдельной работы над дизайн-системой. Бинарник больше.
