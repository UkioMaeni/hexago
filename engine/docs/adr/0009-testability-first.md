# ADR-0009: Headless, фейковые часы и golden-тесты с первого дня

- Статус: принято
- Дата: 2026-11-17

## Контекст

UI-движок, который можно проверить только глазами, деградирует незаметно. Во Flutter `flutter_test`
позволяет прогнать виджет без устройства — это одна из причин его качества.

## Решение

1. `platform/headless` — полноценная платформа: окно и кадровый буфер в памяти, vsync по команде теста.
2. Часы движка — интерфейс; в тестах фейковые: `Pump(16 * time.Millisecond)` двигает время детерминированно.
3. Golden-тесты: сцена → `raster/soft` → PNG → сравнение с `testdata/*.png` с допуском
   (максимальная разница канала и доля отличающихся пикселей — антиалиасинг может чуть «плыть» при
   улучшении алгоритма). Флаг `-update` перезаписывает эталоны; при падении рядом кладётся
   фактическая картинка и карта отличий.
4. `gexagotest` растёт вместе с этапами: M1 — goldens, M4 — `Pump`/finders, M6 — `Tap`/`Drag`.
5. Бенчмарки горячих путей с `testing.AllocsPerRun` — с M1.

## Последствия

- Любой баг воспроизводится тестом без окна; CI не нужна видеокарта.
- Эталонные PNG живут в репозитории — следим за их размером (маленькие сцены).
