# ADR-0011: Без hot reload в v1

- Статус: принято
- Дата: 2026-11-17

## Контекст

Hot reload во Flutter работает благодаря JIT-режиму Dart VM: новый код подменяется в работающем процессе.
Go компилируется заранее (AOT).

## Решение

- В v1 hot reload нет.
- Позже — **hot restart**: `gexago run` следит за файлами, пересобирает и перезапускает приложение,
  сохраняя положение окна и (опционально) снимок состояния через API восстановления
  (аналог `RestorationMixin` во Flutter).
- Держим сборку быстрой: framework без cgo → инкрементальный `go build` за секунды.

## Альтернативы

- Интерпретатор Go (yaegi): поддерживает не весь язык, медленный, другая семантика в мелочах.
- Пакет `plugin`: не работает на Windows и не умеет выгружать код.

## Последствия

- Цикл «правка → результат» — секунды, а не мгновенно. Для учебного проекта приемлемо.
- Widget-тесты и golden-тесты частично заменяют hot reload: результат виден без запуска окна.
