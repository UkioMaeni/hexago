# Hexago для VS Code

- **SDK.** Если команда `hexago` не найдена, расширение спрашивает папку движка Hexago и запоминает её —
  для всех проектов или только для текущего (`.vscode/settings.json`, настройка `hexago.sdkPath`).
  По желанию добавляет `hexago` в PATH.
- **Действия с виджетами** — лампочка или `Ctrl+.`, а также пункт контекстного меню
  «Действия с виджетом…» (`Ctrl+Alt+W`): обернуть в виджет, в Center, Padding, Container, SizedBox,
  Align, Expanded, Column, Row, Stack, Opacity, ClipRRect, SafeArea, Builder; удалить виджет,
  оставив содержимое; поменять местами с ребёнком.
- **Устройство** — справа в строке состояния, как у Flutter: на каком телефоне или эмуляторе запустится
  приложение. По щелчку — подключённые устройства и выключенные эмуляторы («Запустить …»).
  Список обновляется сам (`hexago devices --json --watch`), выбор запоминается для проекта.
- **Команды** (палитра, `Hexago: …`): создать проект, запустить на устройстве (кнопка ▶ Hexago
  в строке состояния), выбрать устройство, проверить окружение, указать путь к SDK.

- **Запуск через F5** (Run → Start Debugging): сборка и запуск на выбранном устройстве, лог — в Debug Console,
  ■ останавливает, ⟳ перезапускает. Настройка в `launch.json`: `{"type": "hexago", "request": "launch"}`,
  необязательное `"device": "Pixel_7"`. Точек останова пока нет.

Кнопки появляются в проекте Hexago (в `go.mod` есть зависимость от `hexago`) — и сразу после
`hexago create .` в уже открытой папке. В недоверенной папке (Restricted Mode) расширение не работает.

## Сборка

```bash
npm install
npm run compile
npm run package          # → hexago.vsix
code --install-extension hexago.vsix
```
